# One Word, One Username, One Reward

This entry sends Zhao's own make.fun username — `lucky-tapir-31-2576` — as a single word and nothing else. The judge's first criterion is that the entry is a real make.fun username, the entrant's own handle, so the program writes exactly that handle to `/output/entry.txt`: one word, no explanation, no links, no pitch. A lucky tapir is a hard name to forget.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (19 characters) to `$MAKEFUN_OUTPUT_DIR`, or `/output` when that is unset. Python 3, standard library only, no network, deterministic.
